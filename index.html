Lección 1

La libreta de Meta: el conjunto de datos

Imagina que Meta le da a tu negocio una libreta con un número. En ella se anota lo que hace la gente contigo: “entró a la web”, “vio el precio”, “dejó sus datos”, “compró”. Esa libreta es el conjunto de datos (en inglés, dataset).

Varios “lápices” pueden escribir en la misma libreta. Después Meta la lee para tres cosas: medir qué anuncio vendió, optimizar (buscar gente parecida a la que compró) y armar públicos (volver a mostrarle el anuncio a quien no compró).

Los puntos verdes son eventos que entran a la libreta. Los ámbar son lo que Meta hace con ellos.

La idea clave: el píxel no es la libreta. El píxel es uno de los lápices. La libreta tiene un solo número (ID), y ese mismo número se usa para el píxel y para la API.

Fuente oficial: Acerca de los conjuntos de datos en el Administrador de eventos (Meta)

Lección 2

El lápiz de la web: el píxel

El píxel es como un anotador sentado en tu web. Cada vez que alguien hace algo importante, levanta la mano y le dice a Meta: “¡alguien vio el precio!”, “¡alguien dejó sus datos!”.

Técnicamente es un pedazo de código JavaScript que se pega en el <head> de cada página. Por eso solo funciona en páginas web: vive dentro del navegador de la persona.

Las 3 líneas que importan

fbq('init', '1234567890');                 // conecta el navegador con TU libreta
fbq('track', 'PageView');                  // "abrió una página"
fbq('track', 'Lead', { content_name: 'Asistente WhatsApp' });  // "dejó sus datos"

Los eventos más usados (nombres oficiales)

EventoCuándo se anotaEjemplo
PageViewAbrió cualquier página (viene con el código base)Entró a la web
ViewContentVio una página o producto importanteLlegó a la sección del precio
LeadDejó sus datos para que lo contactenEnvió el formulario
ContactTe contactó por teléfono, chat o correoTocó el botón de WhatsApp
ScheduleReservó una citaAgendó una demo
PurchaseCompró (con valor y moneda)Página de “gracias por tu compra”
¿El píxel aprende? No, solo anota. Quien aprende es el sistema de anuncios de Meta, cuando tu campaña le dice “busca gente que haga Lead” o “que haga Purchase”.

    Lección 4
    
El lápiz del servidor: la API de conversiones

    
Si el píxel es el anotador que está en la web, la API de conversiones es un mensajero que sale de tu oficina (tu servidor o tu base de datos) y le lleva la noticia directo a Meta, sin pasar por el navegador.

    
¿Por qué existe? Porque el navegador a veces bloquea el píxel (bloqueadores de anuncios, iPhone, mala conexión). Desde el servidor la noticia llega igual. Además, el servidor sabe cosas que la web no ve, como quién pagó por transferencia o Yape.


    

      
      
Meta recomienda mandar el mismo evento por las dos vías. El event_id igual evita contarlo dos veces (deduplicación).

    


    
Así se ve una compra enviada desde el servidor


POST https://graph.facebook.com/v{versión}/{ID_DEL_CONJUNTO}/events
{
  "data": [{
    "event_name": "Purchase",
    "event_time": 1795000000,
    "event_id": "venta-123",
    "action_source": "website",
    "user_data": { "ph": ["<teléfono cifrado con SHA-256>"], "fbc": "fb.1.…AbC123" },
    "custom_data": { "value": 1240, "currency": "PEN" }
  }]
}

    
El teléfono viaja cifrado (hash): Meta lo compara con sus cuentas sin poder leerlo.

    Lección 5
    
Si vendes por WhatsApp: la API para mensajes

    
¿Tener píxel significa que ya no puedes mandar el anuncio a WhatsApp? No. Puedes seguir mandándolo directo al chat. El píxel no participa: aquí escribe en la libreta tu bot, por la API de conversiones para mensajes.


    

      
    


    
Requisitos oficiales para “Maximizar compras a través de mensajes”

    

      
RequisitoQué significa

Que vengan de anunciosSolo cuentan los chats que empezaron con un clic en un anuncio a WhatsApp

      
Dentro de 7 díasLa compra se marca hasta 7 días después del clic

    Lección 6
    
Anuncio → web → WhatsApp: qué ve y qué no

    
Puedes mandar el anuncio a tu web y, desde ahí, a tu WhatsApp. Todo lo que pasa en la web sí se registra. Lo que pasa después dentro del chat (la conversación, la llamada, el pago) el píxel ya no lo ve.


    

      
    

    
Cómo cerrar el círculo: el formulario pidió el teléfono. Cuando esa persona paga por WhatsApp, tu servidor envía un Purchase con ese teléfono cifrado (lección 4), o lo subes en un archivo CSV en el Administrador de eventos. Meta reconoce que es la misma persona que hizo clic.
